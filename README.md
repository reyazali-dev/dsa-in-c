## 📖 About

**DSA in C** is a collection of Data Structures and Algorithms implemented in the C programming language.

This repository documents my journey of learning and implementing fundamental Computer Science concepts during my BCA. The focus is on building a strong understanding of how data structures and algorithms work, while developing clean and efficient implementations.

---

## 📚 Topics

### Data Structures

- Arrays
- Strings
- Linked Lists
- Stacks
- Queues
- Trees
- Graphs
- Hashing

### Algorithms

- Searching
- Sorting
- Recursion
- Dynamic Programming
- Greedy Algorithms
- Backtracking

> More concepts and implementations will be added as I continue learning.

## 🎯 Objectives

- Strengthen C programming fundamentals
- Understand fundamental data structures and algorithms
- Implement concepts from scratch
- Analyze time and space complexity

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/reyazali-dev/dsa-in-c.git
cd dsa-in-c
```

Compile and run any C program using a C compiler such as GCC.

```bash
gcc filename.c -o program
./program
```
